# mythyl

Infographics at [mythyl.art](https://mythyl.art). A subject, made visible.

```
npm install
npm run dev
```

- `/` — landing
- `/conflicts` — map, scored years, Northeast essay

Live records are JSON in `src/data/conflicts/`. Loaders and types live in `src/lib/conflicts/`. Fatality figures are ranges with sources, or omitted.

Research notes (from parallel passes) land in `docs/`.
